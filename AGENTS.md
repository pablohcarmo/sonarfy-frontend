# Verificação de interface

Para alterações de HTML, CSS ou JavaScript que afetem a interface, testar sempre
no Firefox e no Microsoft Edge antes de concluir o trabalho. Verificar desktop
e mobile e, quando disponíveis, os temas claro e escuro. Registrar quais
navegadores foram testados e qualquer limitação de verificação.

Executar também a suíte de testes apropriada às alterações. Preservar alterações
locais do usuário que não façam parte da tarefa.
